## Publication-facing rule

- A named study/program in a table or figure must map to a bibliography entry.
- Site-level analytic units originating from the same source report reuse the same reference number.
- Internal report IDs and legacy shorthand are not used as substitute citations.
- Companion reports may support extraction details but do not receive an independent primary-study citation unless the manuscript specifically relies on the companion for a claim that cannot be supported by the primary report.
- The Bangalore unit remains analytically unchanged; only the publication-facing bibliographic attribution was corrected after direct inspection of the retrievable report.
