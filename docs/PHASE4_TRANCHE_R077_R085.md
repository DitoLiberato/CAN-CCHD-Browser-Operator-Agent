## QA rule clarified by this tranche
A report is not eligible for the primary quantitative synthesis merely because the number of CCHD false positives can be calculated. Protocol criterion 6 requires a diagnosis, clinical outcome, management outcome, or explicit no-diagnosis category among the CCHD-negative failed screens. An echocardiographically CHD-negative infant is not automatically equivalent to an infant with no clinically actionable diagnosis.
